Fluxogramas do Laboratório de Segurança LFD121

Como o projeto funciona, do commit até o login. Cada caixa vermelha é um ponto em que um controle de segurança recusa a operação; as verdes são os caminhos de sucesso. Os nomes em fonte monoespaçada são funções reais de app.py.

1. Pipeline de CI 2. Execução 3. Cadastro 4. Autenticação 5. Limitador
início ou fim processamento decisão sucesso recusado atenção (contando ou bloqueando)

1. Pipeline de CI (seguranca.yml)

Roda em todo push e pull request para main, com permissions: contents: read. Cada ferramenta olha uma camada diferente: o código, as dependências, o comportamento e a imagem final.

2. Execução da aplicação (main())

O que acontece quando o container sobe ou quando você roda python app.py.

3. Cadastro de usuário

A entrada é validada antes de tocar no bcrypt ou no banco. A senha em texto puro nunca é gravada.

4. Autenticação com limitador de tentativas

O fluxo mais importante do projeto. Para quem está de fora, todos os caminhos vermelhos parecem iguais: retornam False com a mesma mensagem genérica. A diferença entre eles só aparece no log interno.

5. Estados do limitador (tabela tentativas_login)

Cada nome de usuário, existente ou não, passa por estes três estados. O estado fica no SQLite e sobrevive a reinícios.
